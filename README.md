# CODSOFT Task 3 – CineMatch AI

## AI Movie Recommendation System

CineMatch AI is an AI-powered movie recommendation web application developed using Python, Flask, Pandas, and Machine Learning.

The application allows users to enter a movie and get recommended movies based on their preferences and movie data.

## Features

- AI-based movie recommendations
- Simple and user-friendly web interface
- Movie search and recommendation
- Flask backend
- Machine Learning-based recommendation system
- Movie dataset using CSV
- Responsive and attractive design

## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS
- JavaScript
